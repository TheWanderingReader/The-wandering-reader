# The Wandering Reader — starter website

This is a free-to-host static website prototype built with plain HTML, CSS, and JavaScript. It uses the brand direction “Midnight at the Library” and includes the provided logo.

## Included
- Responsive homepage and brand story
- Sample product catalog
- Demo shopping bag
- Interactive three-question book-vibe quiz
- Mobile navigation
- Newsletter signup placeholder

## Important before launch
- Product names, prices, descriptions, and art are placeholders. Replace them with current inventory.
- The cart is a front-end demo only; it does not save orders or accept payments.
- The newsletter form does not collect email addresses yet.
- Your uploaded logo is included as `wandering-reader-logo.jpeg`. The next design pass can place it in the header/hero.
- Update content warnings and age/spice guidance for each real book.
- Add your business contact details, social links, pickup/shipping details, privacy policy, and returns policy.

## Test locally
Open `index.html` in a browser. No build step or paid software is required.

## Free hosting option
GitHub Pages can host static HTML/CSS/JS sites for free on a public repository. Once you create a GitHub account, create a repository, upload these files, and enable Pages in the repository settings. A custom domain is optional and generally costs money.

## Free order workflow to start
Until you choose a checkout provider, use a simple order-request form or direct message/email. Payment providers usually charge transaction fees even when there is no monthly subscription.
